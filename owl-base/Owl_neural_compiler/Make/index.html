train ?state ?params ?init_model network x y trains a compiled copy of network. As with Graph.train, init_model (default true) initialises the weights first. To resume a run, pass the state it returned as ~state together with ~init_model:false; the optimiser state saved in it (gradient history, momentum, learning-rate caches) is restored too.
